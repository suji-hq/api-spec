# Suji API spec

Machine-readable OpenAPI 3.1 spec for the public Suji API + an interactive Redoc UI.

- **Spec:** [openapi.yaml](openapi.yaml)
- **Browse:** https://suji-hq.github.io/api-spec/
- **Source of truth:** generated from the Suji monorepo on every push to main; this repo is auto-updated by CI.
- **Stability:** v1 — additive changes only. Breaking changes get a new major version under `/v2`.
- **Changelog:** [CHANGELOG.md](CHANGELOG.md)
